# Working with this repo

This is Eugene's hands-on practice project (Docker Compose → Vagrant → Kubernetes → AWS). See [VAGRANT-GUIDE.md](VAGRANT-GUIDE.md) for the current runbook.

- For routine day-to-day commands (git, vagrant, docker, etc.), give the command to run — don't execute it. This is for learning/practice reps, not automation.
- Read-only inspection (checking state, logs, diagnosing issues) is fine to run directly.
- Keep suggestions terse: the command/action itself, without background reasoning, unless asked to explain.
